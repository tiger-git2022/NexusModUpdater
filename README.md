# NexusModUpdater（N网 Mod 更新）

一个 Windows 小工具：把你在 N 网（Nexus Mods）**下载过的所有 mod** 按游戏汇总起来，自动找出**真正有新文件**的那些，
一键下载更新到对应游戏的 mod 文件夹。不用再去下载记录里按时间翻，也不用在游戏的「最近更新」里大海捞针。

- **按游戏浏览更新**：先在带封面的游戏列表里选一个游戏（游戏名自动显示中文，也能自己改名），再看这个游戏里你下载过、并且之后作者传了新文件的 mod。只检查你选的游戏，不玩的游戏不浪费接口次数；常玩的游戏可以加进「快速切换」栏，下次打开直接回到上次看的游戏。
- **一键更新**：自动选对文件（跟着作者设置的「旧文件 → 新文件」更新链走），下载、解压、替换旧版本（旧版本进回收站）。
- **最小化到托盘**：点关闭时缩到任务栏右下角的托盘，下载和检查在后台继续，完成了会弹通知；单击托盘图标打开，右键可以退出（设置里可以改成点关闭直接退出）。
- **下载页**：左侧「下载」里能看到正在下载的进度、速度，以及所有游戏的下载记录（按天分组，失败的可以重试，完成的可以打开文件夹），重新打开程序记录还在。
- **忽略**：暂时忽略（这次更新不提醒，作者再更新时重新出现）、永久忽略、取消忽略、标记为已是最新；可以多选批量操作。
- **自动翻译外文**：mod 名字、简介、文件说明、更新日志，以及 N 网网页上的评论和简介，只要是外文（英、日、韩、俄、德……）就自动翻译，译文直接替换原文（鼠标停在译文上能看到原文，关掉「翻译」开关恢复原文）；中文内容不翻。装好就能用（免费翻译），填 DeepSeek 等的 Key 翻得更好。
- **评论区**：详情里的「评论」直接看这个 mod 的评论和回复（自动翻译、可翻页）；要发评论点「去 N网发评论」，在内嵌的 N 网页面里发，「写评论（中→英）」把中文翻成英文一键插进评论框。
- **亚克力半透明窗口**，浅色 / 深色主题，和 [WE 加权轮播](https://github.com/tiger-git2022/WallpaperEngineRandom) 同一套界面风格。

## 下载

到 [Releases](../../releases) 下载最新的 `NexusModUpdater.exe`（只有这一个文件，不用解压），放到一个固定文件夹
（例如 `C:\Tools\NexusModUpdater\`），双击打开即可。

- 系统要求：Windows 10 / 11（64 位），自带的 .NET Framework 4.8 和 Edge WebView2，不需要另外安装运行库。
- **更新**：有新版本时窗口左下角会出现提示，点一下就能自动下载新的 exe 并替换，设置和记录不动，完成后自动重新打开；
  也可以在「设置 → 关于」里手动检查。

程序运行时生成的文件（设置、记录、缓存、日志、网页登录状态）都放在 exe 所在的文件夹里，删掉文件夹就彻底卸载。
从 1.0.8 及更早的 zip 版本升级：把新的 `NexusModUpdater.exe` 覆盖旧的就行，旧版本留下的那些 dll 会在第一次打开时自动删掉。

## 第一次使用

1. **填 API Key**：打开「设置 → 账号」，点「获取…」会打开 N 网的 API Keys 页面，把最下面的 **Personal API Key** 复制过来，点「验证」。
   API Key 用来查 mod 信息、文件列表和下载地址。
2. **登录网页**：点左边的「N网」，在内嵌的网页里登录一次（登录状态会保存下来）。程序要读你的
   [下载记录](https://www.nexusmods.com/users/myaccount?tab=download+history)，这个只有网页上有。
3. **（可选）设置翻译**：默认已经能自动翻译；想翻得更好，在「设置 → 翻译」里选 DeepSeek 并填 Key，见下面的「翻译」。
4. **选游戏、检查更新**：回到「Mod 更新」页，在游戏列表里点一个游戏，程序会检查这个游戏的更新（之后也可以点右上角「检查更新」或按 F5）。封面右上角的 ☆ 把游戏加进快速切换栏；右键封面可以改名、设置 mod 文件夹。
5. **设置 mod 文件夹**：在「设置 → 游戏与 mod 文件夹」里给每个游戏选文件夹，或者第一次更新某个游戏的 mod 时程序会问。

## 怎么判断「有更新」

**知道你装了哪些文件时，按文件判断**（本程序装的，或者在 mod 文件夹里认出来的）：
你装的每个文件各自沿着作者设置的「旧文件 → 新文件」更新链（或者同名的新文件）找新版本，有就算更新，点「更新」会把这几个文件都换成新版。
你没装的文件更新了（比如你只装了附加文件，主文件出了新版），**不算你的更新、不会下载**，只在详情里提示一句。

mod 文件夹里的东西怎么认：
- N 网下载的压缩包、解压出来没改过名的同名文件夹：名字里有 modID（新旧两种命名都认）；
- 作者自己起名的文件夹（比如 `PBZMapMarkers`）、改过名的压缩包：拿 N 网给每个文件的「压缩包内容清单」（里面有文件夹名、每个文件的大小和哈希）和你的文件比，对上了就知道是哪个文件的哪个版本；
- 只扫当前游戏的 mod 文件夹和一层子文件夹，只和这个游戏下载记录里的 mod 比。

**不知道你装了哪些文件时（只在下载记录里）**：按下面的时间判断；点「更新」时如果下载之后只出了一个新文件就下它，有多个就弹出列表让你勾选，不乱猜。

- 「你的版本」= 下载记录里的最后下载时间、本程序安装的时间、mod 文件夹里 N 网压缩包（或解压出来、没改过名的同名文件夹）的文件时间，取最新的。N 网现在的文件名形如 `名字 625 1.0 2026-11-08T14-07Z xxxx.zip`，以前的形如 `名字-12345-1-0-1700000000.zip`，两种都认；自己改过名的文件夹认不出来，但这些 mod 靠下载记录一样能查到更新。
- 「最新文件」= 这个 mod 现在主文件 / 更新补丁 / 可选文件里最新的上传时间（不算旧版本和归档）。
- 最新文件比你的版本新，才算有更新。只改了 mod 页面文字、没传新文件的，不会提醒。

为了省接口次数，程序只检查你选中的游戏：先用这个游戏的「最近更新」接口粗筛，只对可能有更新的 mod 查文件列表；mod 的详细信息（图片、简介）每个只查一次，之后用缓存。游戏列表封面上的更新数来自下载记录（不花接口次数），进入游戏检查后才是准确的。

## 下载和安装

- **会员**：点「更新」直接下载。
- **非会员**：点「更新」后程序切到「N网」页并打开这个文件的下载页，点一下 **Slow download**，后面的下载、解压、放文件都会自动完成。
  多个更新会排队，一个一个来。进度和记录在左侧「下载」页。
- 下载更新时选哪个文件：
  1. 本程序装过 / 文件夹里有它的压缩包 → 沿着作者设置的更新链找到对应的新文件；
  2. 只有一个主文件 → 下它；
  3. 有多个主文件，但上次之后只有一个更新过 → 下它；
  4. 还分不出来 → 打开详情让你选（详情的「文件」里每个文件都可以单独下载）。
- 每个游戏可以选放法：
  - **解压到以 mod 命名的子文件夹**（默认，适合 UE 游戏的 `~mods`、大多数 mod 文件夹）；
  - **解压到 mod 文件夹（覆盖）**：程序会记住解压出来的文件，下次更新时先把旧文件移到回收站；
  - **只保存压缩包**：适合交给 MO2 / Vortex 之类的管理器安装。
- 勾选「旧版本移到回收站」时，更新会把上一版移到回收站，误删可以从回收站找回。

## 忽略

| 操作 | 效果 |
|---|---|
| 暂时忽略 | 这次的更新不提醒；作者**再传新文件**时重新出现在「有更新」里 |
| 永久忽略 | 再也不提醒这个 mod（也不再为它查接口） |
| 取消忽略 | 恢复正常 |
| 标记为已是最新 | 不下载，当作已经更新过了（比如在别处装过了） |

列表右边的「⋯」、右键、详情里的「忽略 ▾」，以及勾选多个后上方的批量栏都可以操作；「已忽略」页里能看到所有忽略的 mod。

## 翻译

简介、文件说明、更新日志和 N 网网页上的评论，**只要是外文就自动翻译**（英、日、韩、俄、德等），以中文为主的内容不翻。
在「设置 → 翻译」里选翻译服务，点「申请…」会打开申请 Key 的页面：

| 服务 | 免费额度 | 说明 |
|---|---|---|
| 免费翻译（MyMemory，默认） | 每天约 5000 字，填邮箱约 5 万字 | 不需要 Key，装好就能用；质量一般 |
| DeepSeek（推荐） | 按量付费，翻译很便宜 | 填 API Key；模型默认 `deepseek-flash`（可选 `deepseek-v4-pro`）；思考模式可选关闭 / 长文才开（按词数）/ 总是开，可开「流式输出」 |
| 微软 Azure 翻译 | 每月 200 万字符 | 国内可直连；Azure 门户创建「翻译器」资源，定价层选 F0，复制密钥和区域 |
| DeepL | 每月 50 万字符 | 注册 DeepL API Free，Key 以 `:fx` 结尾 |
| 谷歌云翻译 | 按量计费（有试用额度） | Google Cloud 启用 Cloud Translation API，创建 API 密钥 |
| OpenAI 兼容接口 | 看服务商 | DeepSeek、本地模型（llama.cpp / Ollama / LM Studio）等，填接口地址、Key、模型名 |

DeepSeek 和 OpenAI 兼容接口会把多段文字合成一次请求，评论区几十段只需要几次请求。不想翻译可以选「关闭翻译」。

翻译结果会缓存到 `nmu.translate.json`：原文没变就直接用缓存，不会再请求；原文改了才重新翻；换翻译服务也能用已有的缓存。要重翻可以在设置里点「清空翻译缓存」。「Mod 更新」页右上角和「N网」页工具栏都有「翻译」开关。

## 文件说明

| 文件 | 用途 |
|---|---|
| `nmu.config.json` | 全部设置（含 API Key，不要发给别人） |
| `nmu.state.json` | 下载过的 mod、忽略、本程序的安装记录 |
| `nmu.cache.json` | N 网接口的缓存（mod 信息、文件列表、游戏列表），删掉会重新查 |
| `nmu.translate.json` | 翻译缓存 |
| `nmu.log` | 日志，出问题先看这里（设置 → 查看日志） |
| `webview2/` | 内嵌浏览器的数据（N 网登录状态）；`webview2/loader/` 里是程序启动时释放出来的 WebView2Loader.dll |

## 常见问题

- **提示「N 网网页没有登录」**：到「N网」页登录一次。如果网页弹出人机验证，在「N网」页里完成验证后再点「检查更新」。
- **提示「接口次数用完了」**：N 网接口每天 2500 次、之后每小时 100 次。第一次同步 mod 很多时可能用得比较多，之后每次只查有变化的。
- **非会员点「更新」没反应**：看「N网」页上方的黄色提示，在下载页点「Slow download」。
- **某个 mod 一直显示有更新**：可能是你用别的方式更新过了，用「⋯ → 标记为已是最新」。

## 从源码编译

源码在 `windows/`（C#，.NET Framework 4.8，界面使用 [WPF-UI](https://github.com/lepoco/wpfui) + WebView2）。

```powershell
dotnet build windows\NexusModUpdater.csproj -c Release -o out
```

## 发布流程

改动都在新分支上做，开 PR 到 `main`：PR 上 GitHub Actions 会先编译一遍，编译通过再合并，每次改了什么在 PR 里都能看到。
要发新版本时，在 [CHANGELOG.md](CHANGELOG.md) 顶部加一节 `## [X.Y.Z] - 日期`，随 PR 合并到 `main`。GitHub Actions 发现这个版本号还没有 `vX.Y.Z` 标签，就会自动编译，把编译好的单个 `NexusModUpdater.exe`（依赖都用 Costura 打包在里面）发布到 Releases 并打上标签。最上面一节写成 `- 未发布` 时只编译、不发布。

也可以自己推送形如 `vX.Y.Z` 的 tag 来发布。

更新记录见 [CHANGELOG.md](CHANGELOG.md)。
