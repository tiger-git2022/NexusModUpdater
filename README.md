# NexusModUpdater（N网 Mod 更新）

一个 Windows 小工具：把你在 N 网（Nexus Mods）**下载过的所有 mod** 按游戏汇总起来，自动找出**真正有新文件**的那些，
一键下载更新到对应游戏的 mod 文件夹。不用再去下载记录里按时间翻，也不用在游戏的「最近更新」里大海捞针。

- **按游戏浏览更新**：只显示你下载过、并且之后作者传了新文件的 mod；按游戏分组，可以筛选、搜索、排序。
- **一键更新**：自动选对文件（跟着作者设置的「旧文件 → 新文件」更新链走），下载、解压、替换旧版本（旧版本进回收站）。
- **忽略**：暂时忽略（这次更新不提醒，作者再更新时重新出现）、永久忽略、取消忽略、标记为已是最新；可以多选批量操作。
- **自动翻译**：mod 名字、简介、文件说明、更新日志；N 网网页（评论区、简介）在原文下面显示中文。
- **评论区**：内嵌 N 网页面，直接看评论、发评论；「写评论（中→英）」把中文翻成英文一键插进评论框。
- **亚克力半透明窗口**，浅色 / 深色主题，和 [WE 加权轮播](https://github.com/tiger-git2022/WallpaperEngineRandom) 同一套界面风格。

## 下载

到 [Releases](../../releases) 下载最新的 `NexusModUpdater-vX.Y.Z-win-x64.zip`，解压到一个固定文件夹
（例如 `C:\Tools\NexusModUpdater\`），双击 `NexusModUpdater.exe` 即可。

- 系统要求：Windows 10 / 11（64 位），自带的 .NET Framework 4.8 和 Edge WebView2，不需要另外安装运行库。
- **更新**：有新版本时窗口左下角会出现提示，点一下就能自动下载并替换程序文件，设置和记录不动，完成后自动重新打开；
  也可以在「设置 → 关于」里手动检查。

程序所有文件（设置、记录、缓存、日志、网页登录状态）都放在 exe 所在的文件夹里，删掉文件夹就彻底卸载。

## 第一次使用

1. **填 API Key**：打开「设置 → 账号」，点「获取…」会打开 N 网的 API Keys 页面，把最下面的 **Personal API Key** 复制过来，点「验证」。
   API Key 用来查 mod 信息、文件列表和下载地址。
2. **登录网页**：点左边的「N网」，在内嵌的网页里登录一次（登录状态会保存下来）。程序要读你的
   [下载记录](https://www.nexusmods.com/users/myaccount?tab=download+history)，这个只有网页上有。
3. **检查更新**：回到「Mod 更新」页，点右上角「检查更新」（或按 F5）。第一次会把每个 mod 的信息查一遍，mod 多的话要一两分钟。
4. **设置 mod 文件夹**：在「设置 → 游戏与 mod 文件夹」里给每个游戏选文件夹，或者第一次更新某个游戏的 mod 时程序会问。

## 怎么判断「有更新」

- 「你的版本」= 下载记录里的最后下载时间、本程序安装的时间、mod 文件夹里 N 网压缩包的上传时间，取最新的。
- 「最新文件」= 这个 mod 现在主文件 / 更新补丁 / 可选文件里最新的上传时间（不算旧版本和归档）。
- 最新文件比你的版本新，才算有更新。只改了 mod 页面文字、没传新文件的，不会提醒。

为了省接口次数（N 网每天 2500 次），程序先用每个游戏的「最近更新」接口粗筛，只对可能有更新的 mod 查文件列表。

## 下载和安装

- **会员**：点「更新」直接下载。
- **非会员**：点「更新」后程序切到「N网」页并打开这个文件的下载页，点一下 **Slow download**，后面的下载、解压、放文件都会自动完成。
  多个更新会排队，一个一个来。
- 下载更新时选哪个文件：
  1. 本程序装过 / 文件夹里有它的压缩包 → 沿着作者设置的更新链找到对应的新文件；
  2. 只有一个主文件 → 下它；
  3. 有多个主文件，但上次之后只有一个更新过 → 下它；
  4. 还分不出来 → 打开详情让你选（详情的「文件」里每个文件都可以单独下载）。
- 每个游戏可以选放法：
  - **解压到以 mod 命名的子文件夹**（默认，适合 UE 游戏的 `~mods`、大多数 mod 文件夹）；
  - **解压到 mod 文件夹（覆盖）**：程序会记住解压出来的文件，下次更新时先把旧文件移到回收站；
  - **只保存压缩包**：适合交给 MO2 / Vortex 之类的管理器安装。
- 勾选「旧版本移到回收站」时，更新会把上一版移到回收站，误删可以从回收站找回。

## 忽略

| 操作 | 效果 |
|---|---|
| 暂时忽略 | 这次的更新不提醒；作者**再传新文件**时重新出现在「有更新」里 |
| 永久忽略 | 再也不提醒这个 mod（也不再为它查接口） |
| 取消忽略 | 恢复正常 |
| 标记为已是最新 | 不下载，当作已经更新过了（比如在别处装过了） |

列表右边的「⋯」、右键、详情里的「忽略 ▾」，以及勾选多个后上方的批量栏都可以操作；「已忽略」页里能看到所有忽略的 mod。

## 翻译

在「设置 → 翻译」里选：

- **微软翻译**（默认）：Edge 浏览器内置翻译用的接口，国内可以直连，免费；
- **谷歌翻译**：需要能访问谷歌；
- **OpenAI 兼容接口**：DeepSeek、本地模型（llama.cpp / Ollama / LM Studio）等，填接口地址、Key、模型名。

翻译结果会缓存到 `nmu.translate.json`，同样的文字不会重复翻译。「Mod 更新」页右上角和「N网」页工具栏都有「翻译」开关。

## 文件说明

| 文件 | 用途 |
|---|---|
| `nmu.config.json` | 全部设置（含 API Key，不要发给别人） |
| `nmu.state.json` | 下载过的 mod、忽略、本程序的安装记录 |
| `nmu.cache.json` | N 网接口的缓存（mod 信息、文件列表、游戏列表），删掉会重新查 |
| `nmu.translate.json` | 翻译缓存 |
| `nmu.log` | 日志，出问题先看这里（设置 → 查看日志） |
| `webview2/` | 内嵌浏览器的数据（N 网登录状态） |

## 常见问题

- **提示「N 网网页没有登录」**：到「N网」页登录一次。如果网页弹出人机验证，在「N网」页里完成验证后再点「检查更新」。
- **提示「接口次数用完了」**：N 网接口每天 2500 次、之后每小时 100 次。第一次同步 mod 很多时可能用得比较多，之后每次只查有变化的。
- **非会员点「更新」没反应**：看「N网」页上方的黄色提示，在下载页点「Slow download」。
- **某个 mod 一直显示有更新**：可能是你用别的方式更新过了，用「⋯ → 标记为已是最新」。

## 从源码编译

源码在 `windows/`（C#，.NET Framework 4.8，界面使用 [WPF-UI](https://github.com/lepoco/wpfui) + WebView2）。

```powershell
dotnet build windows\NexusModUpdater.csproj -c Release -o out
```

## 发布流程

在 [CHANGELOG.md](CHANGELOG.md) 顶部加一节 `## [X.Y.Z] - 日期`，合并（或推送）到 `main`。GitHub Actions 发现这个版本号还没有 `vX.Y.Z` 标签，就会自动编译，把打包好的 zip 发布到 Releases 并打上标签。最上面一节写成 `- 未发布` 时只编译、不发布。

也可以自己推送形如 `vX.Y.Z` 的 tag 来发布。

更新记录见 [CHANGELOG.md](CHANGELOG.md)。
